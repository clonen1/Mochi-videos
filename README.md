# Mochi videos

Videos e imagens do Mochi, rumo ao Japao.

## Música (a partir de 02/11)

Fundo lento, suave e simples, com graves: piano (uma nota por segundo), cordas, contrabaixo e violoncelo (mais pizzicato, harpa, celesta).
Nada de som arcade: sem bateria, sem apitos, sem ondas quadradas.
Em `codigo/mochi_audio.py`: `bed()` para o fundo, `piano()`, `strings()`, `cello()`, `contrabass()`, `pizz()`,
`harp_gliss()`, `soft_hit()` e `render_soft()`. Exemplo: `musica_dia5.py`.
